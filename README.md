# Архитектурный квиз по истории Санкт-Петербурга

Веб-приложение в формате игры-квиза для повышения культурного уровня жителей Санкт-Петербурга.

## Что реализовано

- Красивое стартовое меню в архитектурной тематике:
  - `Играть`
  - `Обучение`
  - `Загрузка данных`
- Бесконечный квиз (пока в базе есть данные):
  - Формат 1: текстовый вопрос + 4 фото-ответа.
  - Формат 2: фото здания + 4 текстовых варианта.
- Подсчёт очков за правильные ответы.
- При ошибке показывается:
  - правильный ответ,
  - описание здания,
  - кнопки `Рестарт` и `Перейти к урокам`.
- Раздел `Обучение` с красивой полноэкранной карточкой:
  - фото,
  - название,
  - описание,
  - переключение вперёд/назад.
- Отдельная backend-ручка и UI-форма для загрузки контента:
  - название здания,
  - описание,
  - фотография.

## Технологии

- **Backend:** Python + FastAPI
- **Frontend:** HTML + CSS + JavaScript
- **База данных:** SQLite (`app/history.db`)
- **Статика:** изображения хранятся в `app/static/uploads`

## Структура БД

Таблица `buildings`:
- `id` — первичный ключ
- `name` — название здания (уникально)
- `description` — описание
- `image_path` — путь к изображению
- `created_at` — дата добавления

## Логика генерации вопросов

Для каждого вопроса backend:
1. Случайно выбирает **1 правильное здание**.
2. Случайно выбирает **3 других здания** как отвлекающие варианты.
3. Случайно выбирает режим:
   - `question_to_images` (вопрос → картинки)
   - `image_to_names` (картинка → названия)
4. Перемешивает варианты.

Такой подход позволяет играть очень долго, а при пополнении базы игра становится практически бесконечной.

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть в браузере: `http://127.0.0.1:8000`

## Важные маршруты

### Страницы
- `GET /` — меню
- `GET /play` — игра
- `GET /learn` — обучение
- `GET /admin` — форма загрузки данных

### API
- `GET /api/quiz/next` — получить следующий вопрос
- `POST /api/quiz/check` — проверить ответ
- `GET /api/lessons` — получить список карточек обучения
- `POST /api/admin/buildings` — загрузить новое здание + фото + описание

## Развёртывание на Ubuntu 24.04 (пример)

1. Установить Python 3.12+ и создать venv.
2. Установить зависимости.
3. Запустить через `uvicorn` или `gunicorn + uvicorn workers`.
4. Настроить reverse proxy (например, Nginx) на домен.
5. Убедиться, что папка `app/static/uploads` имеет права на запись для процесса приложения.

## Рекомендации по безопасности для продакшена

Сейчас `/admin` открыт без авторизации (удобно для разработки). Для боевого сервера рекомендуется:

- добавить авторизацию/пароль;
- ограничить размер загружаемых файлов;
- проверять MIME-тип и делать ресайз изображений;
- вынести SQLite в PostgreSQL при росте нагрузки.
